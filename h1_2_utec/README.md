# h1_2_utec

This stack contains ROS 2 packages for the H1-2 Humanoid Robot at UTEC (Universidad de Ingeniería y Tecnología) in Lima, Peru. 

## Supported ROS 2

- Tested with: ROS 2 Humble

## Installation

1. Clone into your ROS 2 workspace `src` folder:

```bash
cd ~/ros2_ws/src
git clone <this-repo-url>
```

2. Build the packages

```bash
cd ~/ros2ws
colcon build --symlink-install
source install/setup.bash
```

If you use a different shell, source the matching setup file.
